# Public release checklist

## P0 before the first GitHub push

- [ ] 项目所有者确认代码归属并选择根目录许可证；确认是否允许公开旧项目的自有实现。
- [ ] 按 `THIRD_PARTY_NOTICES.md` 核对每个第三方库、SDK、APK、PDF 的许可与再分发范围。
- [ ] 扫描所有拟上传文件与 Git 历史中的密钥、服务器地址、私人文档、邮箱和绝对路径。
- [ ] 检查文档、示例图像和样本是否含真实人物、组织、客户或未经授权的数据。
- [ ] `git status` 与 `git ls-files` 均无权重、录制数据、构建产物或个人凭据。
- [ ] 公共契约测试、安装验证与 README 中的命令通过。
- [ ] 明确支持的 Python、Ubuntu、ROS1/ROS2 版本与实际测试环境。
- [ ] 更新 `CHANGELOG.md` 与发布说明；检查版本号与 tag 一致。

## Per-feature PR

- [ ] 提供旧文件到新文件的迁移映射。
- [ ] 新设备输入输出单位、坐标系、时间戳和动作来源有文档与测试。
- [ ] 硬件无关逻辑没有导入 ROS/CAN/Qt/第三方训练框架。
- [ ] 对采集和回放至少使用一份合成或授权样本验证。
- [ ] 真机动作的限位、停止、超时行为经过设备负责人确认。
